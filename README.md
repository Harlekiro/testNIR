# mixuse — сравнение сочетаний функций на территории

Программа для метода НИР «смешанное использование территорий». Территория меняет назначение;
программа показывает, как каждый вариант сочетания функций (Ж, К, ОД, П) скажется на окружающих
кварталах. **Сводного балла и «лучшего варианта» нет** — выбор делает человек.

## Установка

Нужен Python 3.10+ и пакеты numpy, pandas, matplotlib, pyyaml, pytest:

```
pip install -r requirements.txt
```

Геометрия написана на numpy, без geopandas и shapely — ставить ГИС-библиотеки не нужно.

## Как посчитать свои данные

1. Положите слои в одну папку (GeoJSON или GeoPackage):
   - **кварталы** — полигоны (номер квартала — по желанию);
   - **здания** — полигоны с полями: жилое (1/0), этажность, площадь застройки, жилая площадь, жители
     (последние три могут отсутствовать — программа оценит их и напишет об этом в отчёте);
   - **сервисы** — папка «один файл = один тип сервиса» (тип — имя файла: `cafe.geojson`, `school.geojson`…);
     у школ и садов — поле `capacity` (число мест);
   - **зоны** — полигоны с кодом зоны (желательно).

   Слои могут быть в разных системах координат: градусы (EPSG:4326) и зоны UTM программа приводит
   к системе кварталов сама. EPSG:3857 не принимается — в нём искажены площади и расстояния.

2. Составьте файл настроек — программа сделает черновик сама:
   ```
   python -m mixuse init путь/к/папке --name mycity
   ```
   Откройте `configs/mycity.yaml` и проверьте строки с пометкой «ПРОВЕРЬТЕ»: какие поля что значат,
   какие коды зон относятся к П и ОД (`zone_rules`).

3. Проверьте данные:
   ```
   python -m mixuse check configs/mycity.yaml
   ```
   Программа перечислит ошибки (расчёт невозможен) и предупреждения (что принято по умолчанию).

4. Посчитайте таблицу кварталов и найдите номера кварталов территории:
   ```
   python -m mixuse blocks configs/mycity.yaml
   ```
   Откройте `results/mycity_кварталы.geojson` в QGIS — номер квартала в поле `block_id`.

5. Сравните варианты:
   ```
   python -m mixuse compare configs/mycity.yaml --territory 12,13
   ```
   (или впишите `territory: [12, 13]` в настройки).

## Устройство

```
mixuse/
  geometry.py     чтение слоёв, проекция, площадь, точка в полигоне, расстояния (из ноутбука без изменений)
                  + пересчёт градусы ↔ UTM
  groups.py       таблица групп сервисов, группа нежилого здания
  blocks.py       шаги 1–4: таблица кварталов (режимы «слои» и «таблица»), встроенные помещения
  compare.py      шаги 5–6: окружение и показатели
  scenarios.py    варианты
  checks.py       проверка данных; шаги 7 и 7б
  export.py       CSV, GeoJSON для QGIS, JSON для страницы, карта
  config.py       файл настроек YAML
  init_config.py  черновик настроек по папке с данными
  cli.py          командная строка
  params.py       параметры по умолчанию — в одном месте
  data/таблица_групп_сервисов.csv   тип сервиса → группа (своя таблица — service_groups: в настройках)
configs/          spb.yaml, gatchina.yaml, vysotsk.yaml — примеры
examples/         данные примеров (не входят в репозиторий)
tests/            тесты; tests/etalon — эталоны ноутбука
```

Тесты: `python -m pytest tests`.

## История изменений

### 0.1.0 — 17.11.2026. Перенос ноутбука в пакет (этап 1)

- Расчёт шагов 1–9 перенесён из `листинг_метода.py` (ноутбук от 29.10.2026) без изменений формул.
  При `builtin: нет` таблицы кварталов, сравнения и устойчивости совпадают с эталонами `results/`
  для spb и gatchina (тесты `tests/test_etalon.py`).
- **Новое в расчёте: встроенные помещения** (по ТЗ, п. 4.3.4), переключатель `builtin`, по умолчанию «да».
  В жилом доме не ниже 2 этажей с n сервисами К и ОД внутри: B = min(n · 100, 0,5 · S),
  B делится между К и ОД по числу сервисов. Как видно в результатах: растут `nr_К`, `nr_ОД`, рабочие
  места и K; новые столбцы `встр_К`, `встр_ОД`. Числа ТЗ (345 домов, 56 390 / 7 300 м²) пока
  **не воспроизводятся** (у нас 350 / 56 325 / 8 367) — нужна новая версия ноутбука автора.
- **Новое в подготовке данных: слои в разных системах координат** приводятся к системе кварталов
  (градусы ↔ UTM). В ноутбуке такие слои молча не совпадали бы. На числа spb и gatchina не влияет
  (у них все слои в одной системе).
- Отчёт о подготовке дополнен счётчиками: здания без этажности, без числа жителей, школы и сады без
  числа мест, нежилые здания меньше S_min, как определена группа нежилых зданий.
- Справочник групп сервисов вынесен в CSV (43 типа — как в ноутбуке). Коды ВРИ не заполнены —
  [НУЖЕН ИСТОЧНИК]: таблица на 108 типов у автора.
