МЕТОД СРАВНЕНИЯ СОЧЕТАНИЙ ФУНКЦИЙ — ноутбук, таблица групп, страница и данные

Что внутри
  метод_сравнения_вариантов.ipynb   ноутбук-шаблон для своих данных: анкета «Шаг 0» (пути к слоям и имена
                                    полей) → проверка данных → таблица кварталов → сравнение вариантов
  пример_расчёта_ВО.ipynb           тот же ноутбук, выполненный на данных Васильевского острова (для образца)
  таблица_групп_сервисов.csv        какой тип сервиса к какой группе относится (К, ОД, П, школа, детский_сад,
                                    метро, остановка, нет); группа задана по коду ВРИ; открывается в Excel
  конструктор_смешанности.html      страница: открыть в браузере, перетащить results/<код>_для_страницы.json
                                    (или GeoJSON кварталов из QGIS); проверяет данные и сравнивает варианты
  листинг_метода.py                 весь код ноутбука с описанием каждого блока и функции (для приложения НИР)
  data/spb_vasilievsky/             Васильевский остров: кварталы, здания, сервисы (папка: один файл — один тип),
                                    функциональные зоны (из github.com/IDUclub/blocksnet-data)
  data/vysotsk/                     Высоцк: кварталы (пересохранены в EPSG:4326), здания, зоны генплана,
                                    сервисы и промышленность (две папки: один файл — один тип)
  data/gatchina/                    Гатчина: готовая таблица кварталов — здания и сервисы уже присоединены
                                    (релиз v2026-data-gatchina, github.com/Eynor-K/blocksnet-agent)
  results/                          результаты для всех трёх примеров: таблица кварталов, сравнение вариантов,
                                    устойчивость, карта, слой для QGIS, файл для страницы

Как посчитать свои данные
  1. Положить слои в папку data/<свой_город>/: кварталы (полигоны), здания (полигоны),
     сервисы (точки или полигоны; папка «один файл — один тип» или один файл с полем типа),
     по желанию — зоны (полигоны).
  2. Открыть метод_сравнения_вариантов.ipynb (Jupyter, VS Code или Google Colab).
  3. В ячейке «Шаг 0. Ваши данные» вписать пути к файлам, имена полей и номера кварталов территории.
  4. Run All. Ячейка «Шаг 0б» покажет, что нашлось в слоях; при ошибках (✕) расчёт остановится
     и подскажет, что исправить.
  5. Если проверка пишет «типов нет в таблице групп» — добавить строки в таблицу_групп_сервисов.csv
     (тип, название, код ВРИ, группа).

Как посчитать примеры
  В ячейке «Примеры заполнения» поставить ПРИМЕР = 'spb', 'vysotsk' или 'gatchina' и выполнить все ячейки.

Нужно: Python 3.10+ с numpy, pandas, matplotlib (есть в Anaconda и Google Colab).

Изменение от 16.11.2026: встроенные помещения в жилых домах
  Если внутри контура жилого дома (не ниже 2 этажей) есть сервисы групп К или ОД, часть его первого этажа
  считается нежилой: B = min(n · s0, 0,5 · S), где n — число таких сервисов в доме, s0 = 100 м² — площадь одного
  помещения (допущение), S — площадь застройки дома; 0,5 — доля этажа, обращённая к улице. Площадь B делится
  между К и ОД пропорционально числу сервисов и добавляется к нежилой площади этих групп (столбцы «встр_К»,
  «встр_ОД» таблицы кварталов); с неё считаются рабочие места. Жители дома не меняются.
  Параметры: builtin (True/False), builtin_s0 (100), builtin_share (0.5), builtin_min_storeys (2).
  При builtin=False результаты совпадают с прежней версией.
  Новый шаг 7б: пересчёт без встроенных помещений и при s0 = 50, 100, 300 м² → results/<код>_встроенные.csv.
  В режиме «таблица» (Гатчина) правило не применяется — нет слоя зданий; результаты Гатчины не изменились.
  Файл пример_расчёта_ВО.ipynb: код обновлён, выводы очищены — выполнить Run All.
